Market-TECH Autofill

Automate Flipkart and Meesho listing uploads: record, save and instantly run form profiles without repetitive typing.

Install

  1. Download the extension files from this site or load the folder public/extensions/market-tech/ unpacked.
  2. Open Chrome and go to chrome://extensions.
  3. Enable Developer mode.
  4. Click Load unpacked and select the extension folder.
Login is compulsory

The Market-TECH extension is locked until you sign in. Capture and run of profiles requires a valid Market-TECH account session — no local bypass.
