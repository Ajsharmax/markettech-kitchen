# MarketTech Applications

Private, in-browser PDF tools. Files are processed on the visitor's device and are never uploaded.

## Layout
- `registry.js` is the single list of tools. A `ready` entry needs a spec in `tools/<module>.js`; a `coming-soon` entry needs a `reason`.
- `core.js` is the shared engine: library loading, drop zone, file list, options form, progress and cancel, password dialog, ZIP and download helpers, page-range parsing.
- `stage.js` is the page-with-draggable-boxes component used by Crop, Redact, Sign and Label Crop.
- `tools/pages.js` (merge, split, remove, extract, rotate, page numbers, watermark, details), `tools/convert.js` (images to PDF, PDF to images, text, Word, compress, grayscale, compare), `tools/visual.js` (crop, organize, redact, sign), `tools/label-crop.js` (Label Crop 4×6).
- `tool.js` loads the right module for each page. Each tool has a real static page, generated by `npm run build:tools`.

## Adding a tool
1. Add an entry to `registry.js` and a spec in the matching `tools/*.js` file. A simple tool is a spec with `accept`, `options` and `run()`; a visual tool sets `custom: true` and `mount(root)`.
2. Run `npm run build:tools` to create its page, then `npm test`.

## Privacy
- pdf.js 3.11.174, pdf-lib 1.10.0 and JSZip 3.10.1 are self-hosted in `vendor/`. No CDN is used.
- Pages carry a Content-Security-Policy with `connect-src 'self'` (meta tag and `_headers`), so the page cannot send data elsewhere.
- Verify in the browser Network tab while running a tool: there should be no requests after the page loads.

## Known limits
- pdf-lib cannot read password-protected PDFs. The tools say so; Unlock PDF is marked Coming soon.
- Compress (Balanced and Strong), Grayscale and Redact turn pages into images, so text is no longer selectable.
- PDF to Word keeps text only. Word, Excel and PowerPoint to PDF, PDF to Excel/PowerPoint, OCR, Protect/Unlock, Repair and HTML to PDF are Coming soon with the reason shown on each card.
- Tools run on the main thread with progress and a Cancel button between pages; very large files (100 MB+) can be slow.
- Signature is an image, not a certified digital signature.
